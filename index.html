Documentação da API de Eventos

API REST utilizada para consulta de eventos. Os dados são retornados no formato JSON e podem ser consumidos por aplicações front-end por meio de requisições HTTP.

URL base https://api-eventos-tau.vercel.app

Endpoints disponíveis

GET /eventos

Retorna a lista completa de eventos disponíveis.

Exemplo de requisição 
GET https://api-eventos-tau.vercel.app/eventos
Formato da resposta 
[
  {
    "id": 1,
    "titulo": "Workshop de React",
    "descricao": "Aprenda os principais conceitos para criar interfaces modernas e componentizadas com React.",
    "descricaoCompleta": "Este workshop apresenta uma introdução prática ao desenvolvimento de interfaces com React...",
    "data": "2026-10-20",
    "horario": "19:00 às 22:00",
    "local": "Centro de Treinamento",
    "categoria": "Tecnologia",
    "modalidade": "Presencial",
    "vagas": 25,
    "inscricao": "Gratuita",
    "imagem": "https://..."
  }
]
GET /eventos/:id

Retorna os dados de um único evento a partir de seu identificador.

Exemplo de requisição 
GET https://api-eventos-tau.vercel.app/eventos/1
Formato da resposta 
{
  "id": 1,
  "titulo": "Workshop de React",
  "descricao": "Aprenda os principais conceitos para criar interfaces modernas e componentizadas com React.",
  "descricaoCompleta": "Este workshop apresenta uma introdução prática ao desenvolvimento de interfaces com React...",
  "data": "2026-10-20",
  "horario": "19:00 às 22:00",
  "local": "Centro de Treinamento",
  "categoria": "Tecnologia",
  "modalidade": "Presencial",
  "vagas": 25,
  "inscricao": "Gratuita",
  "imagem": "https://..."
}

Substitua :id pelo identificador do evento desejado. Exemplo: /eventos/3.

GET /categorias

Retorna as categorias disponíveis nos eventos cadastrados.

Exemplo de requisição 
GET https://api-eventos-tau.vercel.app/categorias
Formato da resposta 
[
  "Tecnologia",
  "Design",
  "Desenvolvimento",
  "Negócios"
]
GET /eventos?categoria=Tecnologia

Retorna apenas os eventos pertencentes à categoria informada.

Exemplo de requisição 
GET https://api-eventos-tau.vercel.app/eventos?categoria=Tecnologia
Formato da resposta 
[
  {
    "id": 1,
    "titulo": "Workshop de React",
    "categoria": "Tecnologia",
    ...
  },
  {
    "id": 3,
    "titulo": "Introdução ao Node.js",
    "categoria": "Tecnologia",
    ...
  }
]

Estrutura dos dados

Campo Tipo Descrição
idNumberIdentificador único do evento.
tituloStringNome do evento.
descricaoStringDescrição resumida do evento.
descricaoCompletaStringDescrição detalhada do evento.
dataStringData no formato AAAA-MM-DD.
horarioStringHorário previsto para realização.
localStringLocal de realização.
categoriaStringCategoria à qual o evento pertence.
modalidadeStringModalidade de realização do evento.
vagasNumberQuantidade de vagas disponíveis.
inscricaoStringInformação sobre a inscrição.
imagemStringURL da imagem do evento.

Exemplo de consumo

Uma requisição pode ser realizada utilizando a API nativa fetch() do JavaScript.

fetch("https://api-eventos-tau.vercel.app/eventos")
  .then(response => response.json())
  .then(data => {
    console.log(data);
  });

Códigos de resposta

Código Significado
200 Requisição realizada com sucesso.
404 Evento não encontrado ao consultar um identificador inexistente.
Exemplo de erro 
{
  "erro": "Evento não encontrado"
}
