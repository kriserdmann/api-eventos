Documentação da API de Eventos

API REST utilizada para consulta de eventos. Os dados são retornados em JSON e podem ser consumidos por aplicações front-end.

URL base da API https://api-eventos-tau.vercel.app/api

Endpoints disponíveis

GET /api/eventos

Retorna a lista completa de eventos disponíveis.

Exemplo de requisição 
GET https://api-eventos-tau.vercel.app/api/eventos
Formato da resposta 
[
  {
    "id": 1,
    "titulo": "Workshop de React",
    "descricao": "Aprenda os principais conceitos para criar interfaces modernas e componentizadas com React.",
    "descricaoCompleta": "Este workshop apresenta uma introdução prática ao desenvolvimento de interfaces com React...",
    "data": "2026-10-20",
    "horario": "19:00 às 22:00",
    "local": "Centro de Treinamento",
    "categoria": "Tecnologia",
    "modalidade": "Presencial",
    "vagas": 25,
    "inscricao": "Gratuita",
    "imagem": "https://..."
  }
]
GET /api/eventos/:id

Retorna os dados de um único evento a partir do identificador.

Exemplo de requisição 
GET https://api-eventos-tau.vercel.app/api/eventos/1
Formato da resposta 
{
  "id": 1,
  "titulo": "Workshop de React",
  "descricao": "Aprenda os principais conceitos para criar interfaces modernas e componentizadas com React.",
  "descricaoCompleta": "Este workshop apresenta uma introdução prática ao desenvolvimento de interfaces com React...",
  "data": "2026-10-20",
  "horario": "19:00 às 22:00",
  "local": "Centro de Treinamento",
  "categoria": "Tecnologia",
  "modalidade": "Presencial",
  "vagas": 25,
  "inscricao": "Gratuita",
  "imagem": "https://..."
}
Substitua :id pelo identificador do evento desejado.
GET /api/categorias

Retorna as categorias disponíveis.

[
  "Tecnologia",
  "Design",
  "Desenvolvimento",
  "Negócios"
]
GET /api/eventos?categoria=Tecnologia

Retorna os eventos pertencentes à categoria informada.

GET https://api-eventos-tau.vercel.app/api/eventos?categoria=Tecnologia

Estrutura dos dados

Campo Tipo Descrição
idNumberIdentificador único do evento.
tituloStringNome do evento.
descricaoStringDescrição resumida.
descricaoCompletaStringDescrição detalhada.
dataStringData no formato AAAA-MM-DD.
horarioStringHorário do evento.
localStringLocal de realização.
categoriaStringCategoria do evento.
modalidadeStringModalidade de realização.
vagasNumberQuantidade de vagas.
inscricaoStringInformação sobre inscrição.
imagemStringURL da imagem.

Exemplo de consumo

fetch("https://api-eventos-tau.vercel.app/api/eventos")
  .then(response => response.json())
  .then(data => {
    console.log(data);
  });

Códigos de resposta

Código Significado
200Requisição realizada com sucesso.
404Evento não encontrado.
 
{
  "erro": "Evento não encontrado"
}
